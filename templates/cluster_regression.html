What is Cluster-Augmented Regression?

This technique involves initially applying an unsupervised clustering algorithm (like K-Means) to the dataset to discover hidden subgroups. The resulting cluster labels are then one-hot encoded and added to the original dataset as new features. A supervised regression model is then trained on this augmented dataset, often leading to better performance as the model can adjust its predictions based on the inherent clustered structures in the data.

from sklearn.cluster import KMeans
from sklearn.linear_model import LinearRegression
import pandas as pd

# 1. Unsupervised Step: Find hidden clusters
kmeans = KMeans(n_clusters=4, random_state=42)
clusters = kmeans.fit_predict(X_scaled)

# 2. Augmentation Step: Add clusters as One-Hot encoded features
X_aug = X.copy()
X_aug['Cluster'] = clusters
X_aug = pd.get_dummies(X_aug, columns=['Cluster'], drop_first=True)

# 3. Supervised Step: Train regression on augmented dataset
